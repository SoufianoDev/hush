Hush

Privacy policy

Last updated: November 1, 2026

What Hush does

Hush is a local plugin and instruction package for coding agents. It guides the host agent to keep code comments useful, preserve meaningful comments and directives, and limit cleanup to code changed in the current task.

Data collected by Hush

Hush does not operate a server, collect telemetry, create an account, receive source code, or transmit prompts or project files to its maintainers. The plugin reads its bundled instruction file from its own installed package and adds those instructions to the host agent's context.

Host applications

The coding-agent or AI service you choose processes prompts and project context under its own privacy policy and account settings. Hush does not control the host provider's processing, retention, or model training settings.

External services

Hush makes no outbound network requests during normal plugin execution. Package managers and marketplace clients may contact their own registries or provider services when you install or update the package.

Contact

For questions about this policy, use the contact information published in the Hush source repository. Before submitting Hush to a public plugin directory, the publisher must add a monitored support contact and ensure this policy is hosted at the final public URL.
