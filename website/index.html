One project · multiple native integrations

Useful comments.
Less noise.

Hush is a coding-agent plugin that keeps comments only when they explain something the code cannot. It preserves directives and real context, limits cleanup to code changed in the current task, and follows the project's formatter.

View source and installChoose your app

No remote service, account connection, source upload, or external dependency is required by Hush itself.

Native plugin integrations

Install in your coding app

Each host has its own plugin contract. Hush ships native manifests and one TypeScript plugin entrypoint where the APIs differ.

Native plugin

Claude Code

Register the repository marketplace, then install Hush from Claude Code's plugin panel.

You can also run the slash command inside a Claude Code session: /plugin marketplace add .

Plugin browser

Codex

Add the repository marketplace, open the plugin browser, then install Hush from the marketplace list.

The repo marketplace lives at .agents/plugins/marketplace.json.

OpenCode V1 · 1.18.29+

OpenCode V1

Add the npm package to the singular plugin array in the global or project OpenCode config.

When Hush's repository is the active workspace, the included .opencode/plugins/hush.ts shim loads the project-local plugin. Global package installation requires the npm package to be published first.

OpenCode V2

OpenCode V2

Install the GitHub package with the V2 plugin manager, then type @hush in chat to invoke the skill directly.

V2 uses the plural plugins config and its own setup() API. The package exposes both V1 and V2 implementations.

Native plugin bundle

Antigravity

Install the repository plugin from Antigravity CLI. Open Customizations to inspect the installed plugin.

Hush uses the dedicated .antigravity-plugin/plugin.json manifest so it can coexist with the OpenAI manifest at the repository root. Marketplace listing is a separate Google partner submission.

MiMo Code plugin

MiMo Code

Use MiMo Code's native plugin configuration. The plugin uses MiMo's own V1-compatible host contract and config directories.

The repository includes a project-local .mimocode/plugin/hush.ts shim. Global package installation requires npm publication and MiMo's own plugin config; MiMo Code does not use OpenCode's plugin folder.

OpenCode V1 and V2 are not the same plugin API. Hush's single `src/index.ts` exports a V1 `server()` and a V2 `setup()` implementation. The shared entrypoint's V1 object format requires OpenCode 1.18.29 or later.
Browser-based products

Install from the web

Web apps do not expose the same plugin installation contract as their coding CLIs. These are the official browser routes.

Claude Web · Native plugin

Claude

Install the same Hush Claude plugin used by Claude Code. Claude Web can add a Git repository marketplace or accept a custom plugin ZIP.

  1. Open Claude → Customize → Plugins.
  2. Select Add → Add marketplace → Add from a repository.
  3. Enter the public GitHub repository shown below.
  4. Open Discover, find Hush, then click Add.

Alternatively, upload dist/hush-claude-plugin.zip as a custom plugin file. Plugins added on the web are saved to your account and follow you across Chat, Cowork, and Claude Code.

ChatGPT Web · Public plugin

ChatGPT

The portable Hush Plugin contains the same skill. Upload it to OpenAI's public Plugins Directory to make it discoverable from ChatGPT Web.

  1. Deploy this project and its privacy page.
  2. Verify the publisher and complete listing/support details.
  3. Upload dist/hush-openai-plugin.zip in the Plugins portal.
  4. Pass automated checks, submit for review, then publish when approved.
